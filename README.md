## 🏛️ Hakikat & Visi Holistik

Math Lab bukan sekadar kalkulator grafis atau kumpulan rumus terisolasi. Math Lab dirancang sebagai **Laboratorium Eksplorasi Matematika Universal** yang menghubungkan konsep secara fundamental dan melayani tiga pilar ekosistem pendidikan:

```
                      ┌─────────────────────────────────┐
                      │            MATH LAB             │
                      │  Universal Mathematical Engine  │
                      └────────────────┬────────────────┘
                                       │
        ┌──────────────────────────────┼──────────────────────────────┐
        │                              │                              │
        ▼                              ▼                              ▼
┌───────────────┐              ┌───────────────┐              ┌───────────────┐
│   PILAR 1     │              │   PILAR 2     │              │   PILAR 3     │
│ SISWA & GURU  │              │  KAMPUS/RISET │              │ MANAJEMEN EDU │
│ Eksplorasi    │              │ Telemetri R&D │              │ Peta Mutu     │
│ Konsep &      │              │ Analisis PCM, │              │ Kurikulum &   │
│ Miskonsepsi   │              │ N-Gain, SPSS  │              │ Rapor ANBK    │
└───────────────┘              └───────────────┘              └───────────────┘
```

1. **Pilar Siswa & Guru (Sekolah Menengah & Dasar: Fase D/E/F):**
   - Mengubah hafalan rumus mati menjadi pemahaman relasional (*Skemp's Relational Understanding*).
   - Memanipulasi variabel secara dinamis (< 16 ms) untuk mengamati invarian dan kovariansi.
   - Mengatasi miskonsepsi kronis (misal: arah geser parabola, makna spasial Pythagoras, makna koordinat trigonometri).
2. **Pilar Kampus & Riset Pendidikan Matematika (Dosen & Mahasiswa S1/S2/S3):**
   - **Didactic Behavioral Telemetry:** Merekam jejak interaksi belajar siswa secara etis (transisi antar register semiotik Duval, waktu henti, urutan manipulasi) untuk penelitian eksperimen semu, PTK, atau R&D (Model 4D, ADDIE, Plomp).
   - **Ekspor Data Siap Riset:** Mengunduh data log interaksi ke format CSV/JSON terstandarisasi untuk analisis model pengukuran (Rasch, Partial Credit Model) di R, Python, SPSS, atau Jamovi.
   - **Kajian Etnomatematika & Pemodelan Tinggi:** Wahana komputasi visual untuk merekonstruksi matematika pada artefak budaya lokal dan fenomena sains modern.
3. **Pilar Manajemen Pendidikan & Kebijakan (Kepala Sekolah, Pengawas, Dinas):**
   - **Diagnostic Aggregation Dashboard:** Memetakan titik lemah dan miskonsepsi konsep siswa secara agregat tanpa mempermalukan individu.
   - **Intervensi Berbasis Bukti:** Menyediakan data empiris untuk perbaikan mutu pembelajaran yang terhubung dengan indikator Rapor Pendidikan (Asesmen Nasional / ANBK) dan standar PISA.
   - **Pemodelan Keputusan Operasional:** Simulasi matematika aplikatif untuk efisiensi anggaran, penjadwalan, dan perencanaan fasilitas pendidikan.

## 🎯 Spektrum Lengkap: Dari Teori Keilmuan Hingga Tugas Multi-Persona

Math Lab dirancang untuk melayani kesinambungan kognitif dan operasional dari ruang kelas dasar hingga kebijakan kelembagaan:

| Dimensi | Cakupan pada Math Lab | Contoh Wujud Nyata |
| :--- | :--- | :--- |
| **Pemahaman Konsep** | Menyingkap prinsip invarian, kovariansi, dan relasi aljabar-geometri. | Memahami mengapa $(x - h)^2$ menggeser parabola ke kanan, bukan ke kiri. |
| **Pemahaman Konteks** | Menghubungkan matematika dengan fenomena fisis, sosial, dan etnomatematika. | Lintasan proyektil basket, motif fraktal batik, dan simulasi panen hidroponik. |
| **Pemahaman Teori** | Memvisualisasikan bukti formal, translasi register semiotik Duval, dan kalkulus. | Pembuktian visual puzzle luas Euclid untuk Teorema Pythagoras $a^2 + b^2 = c^2$. |
| **Pembelajaran** | Eksplorasi terbimbing (*guided inquiry*) dan remediasi miskonsepsi mandiri. | Siswa menguji hipotesis sebelum rumus formal disajikan oleh guru di kelas. |
| **Penelitian** | Instrumen R&D (Model 4D Thiagarajan/Plomp), PTK, dan eksperimen semu. | Pengujian validitas Aiken's $V \ge 0.78$, skor kepraktisan SUS, dan efektivitas $N\text{-gain}$. |
| **Praktikal / Terapan** | Pemodelan matematika untuk keputusan manajemen dan sains terapan. | Simulasi anggaran BOS, optimasi rasio guru-siswa, dan kalkulasi titik impas. |

### Matriks Dukungan Penugasan Berdasarkan Persona Pengguna

* **Siswa (SMP/SMA):** Mengerjakan Lembar Kerja Peserta Didik (LKPD) digital/cetak interaktif, menjawab kuis prediksi formatif, dan menyusun portofolio eksplorasi konsep.
* **Mahasiswa (S1/S2/S3):** Menyelesaikan tugas mata kuliah Desain Media Matematika, tugas pemodelan numerik, serta mengumpulkan data mentah telemetri untuk skripsi/tesis eksperimen.
* **Guru Matematika:** Merancang modul ajar Kurikulum Merdeka, membagikan tugas eksplorasi berbasis URL instan tanpa login, dan mendiagnosis miskonsepsi kelas sebelum ulangan sumatif.
* **Dosen:** Menyajikan media perkuliahan Aljabar, Geometri, Kalkulus, atau Statistik Pendidikan; membimbing penelitian mahasiswa dengan *data lineage* bebas manipulasi; serta menjalankan PKM pelatihan guru.
* **Lembaga (Sekolah, Pengawas, Dinas):** Memetakan peta mutu numerasi agregat sekolah untuk evaluasi kurikulum, menyelaraskan target ANBK/PISA, dan membuat proyeksi manajerial sekolah.

## 🧭 Desain Antarmuka: The Trinity Canvas (Bento-Grid Minimalis)

Sesuai dengan standar estetika *Warm Editorial* dan *Cognitive Load Theory*, antarmuka Math Lab membagi layar menjadi 3 ruang komparatif terpadu:

1. **Kanvas Visual Reaktif (SVG Native 60 FPS):** Menampilkan bidang Cartesius, bentuk spasial geometris, atau lintasan gerak dinamis.
2. **Inspektur Dual-Register (Aljabar & Parameter):** Persamaan aljabar dinamis KaTeX yang tersinkronisasi sempurna dengan slider variabel invarian/kovariansi.
3. **Panel Konteks & Diagnostik Didaktik:** Menghadirkan skenario fisis dunia nyata, tugas prediksi berbasis *Partial Credit Model*, dan intepretasi naratif manusiawi.

Pada perangkat bergerak (*smartphone*), tata letak ini bertransformasi menjadi tab tersegmentasi yang adaptif (*swipeable*).

## 🛠️ Arsitektur Teknologi

- **Frontend Core:** React 19, TypeScript 5.7, Vite 6
- **Mathematical Engine:** Pure TypeScript Deterministic Domain Module (toleransi *epsilon* floating-point, zero heavy vendor lock-in)
- **Visual Rendering:** Reactive Native SVG Canvas (crisp Retina, accessible via DOM ARIA, zero canvas memory leaks)
- **Mathematical Typesetting:** KaTeX
- **Styling:** Minimalist Warm Editorial Vanilla CSS Tokens (bebas *AI slop*, kontras WCAG 2.2 AAA)
- **Edge API & Persistence:** Hono pada Cloudflare Pages Functions / Workers & Cloudflare D1
- **Programmatic SEO (pSEO) & SXO:** Pre-rendered pages per konsep kurikulum dengan Schema.org `LearningResource` dan URL hash state sharing
